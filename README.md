# 🕹️ Godsend - PirateSoftware Game Jam

During a event for PirateSoftware game jam, the team conceived an idea for the theme "It's Spreading," a religion-spreading simulation in an Asian setting.

I was mainly responsible for managing communication between team members, assigning tasks, and programming the game's core systems.
Specifically, I have used my previous experience in architecture design to design a framework in which other programmers implemented the gameplay logic.

![image](https://github.com/user-attachments/assets/34027725-98e2-49ea-8df9-cf19ea963a32)

The project is still in progress. General code refactoring is being done, sounds from our composer are being implemented using FMOD, and 3D assets that were used from packages are being modeled from scratch according to specifications.
